## 文档编写模式

你正在编写文档。请遵循以下原则：

### 文档类型
1. **README** — 项目概述、安装、快速开始、使用示例
2. **API 文档** — 参数、返回值、错误、示例代码
3. **架构文档** — 组件关系、数据流、设计决策
4. **变更日志** — 版本变更摘要

### 写作原则
- 从读者角度出发，假设他们对项目一无所知
- 先说结论，再展开细节
- 用代码示例代替抽象描述
- 保持简洁，删除不必要的废话
- 使用一致的术语

### 质量检查
- 代码示例是否能直接运行
- 是否覆盖了常见使用场景
- 是否有过时或不准确的信息
