## 调试模式

你正在调试一个问题。请按以下流程：

### 调试流程
1. **收集信息** — 错误信息、堆栈跟踪、复现步骤
2. **缩小范围** — 确定问题发生的代码区域
3. **形成假设** — 基于症状提出可能的原因
4. **验证假设** — 通过阅读代码或添加日志验证
5. **修复问题** — 最小化修改解决根因
6. **验证修复** — 确保修复有效且不引入新问题

### 调试技巧
- 读错误信息要从头读到尾
- 检查最近的变更（git log/diff）
- 二分法定位（注释代码、折半排查）
- 添加临时日志/断言确认状态
- 检查环境差异（配置、版本、权限）

### 输出要求
- 描述根因（不只是症状）
- 解释为什么这个修复方案
- 是否需要额外的防御性措施
